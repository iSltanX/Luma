حدّث صفحة حالة المشروع وانشرها. الرابط ثابت لا يتغيّر:

**`https://claude.ai/code/artifact/dd2410b5-d5bb-4160-bc61-5a4ce1e7fa88`**

## الخطوات

1. إن كانت هناك لقطات جديدة في `docs/evidence/` بلا تسمية، أضف لكلٍّ تسمية عربية قصيرة في `docs/site/captions.json`.

2. أعد التوليد:

   ```bash
   npm run site
   ```

   يقرأ المولّد `PLAN.md` وسجل git و`docs/decisions/` و`docs/evidence/` و`Luma.md` §٢٠ و`IMPLEMENTATION.md` §١٨ وطبقة الرموز، ويشغّل اختبارات الوحدة ليأخذ عددها. `--fast` يتخطّى الاختبارات و`--no-img` يتخطّى اللقطات.

3. انشر بأداة `Artifact` **مع تمرير `url` أعلاه** وإلا أنشأت رابطًا ثانيًا:

   - `file_path`: `docs/site/index.html`
   - `url`: الرابط أعلاه
   - `favicon`: `🪶` — لا يتغيّر
   - `label`: وصف موجز مثل «المرحلة ٧» أو «حُسمت المسألة ١٧»

4. أخبر المستخدم بما تغيّر على الصفحة: المراحل التي اكتملت، والمسائل التي حُسمت، والقرارات الجديدة، وعدد الفحوص.

## قواعد

- **لا تحرّر `docs/site/index.html` يدويًا** — مخرَج مولَّد، ويُمحى عند التوليد التالي.
- **لا حالة مكتوبة يدويًا في المولّد** — اكتمال المرحلة يُشتق من وجود التزام `المرحلة ن:` في السجل. المرحلة تظهر مكتملة حين تُلتزَم، لا قبلها.
- التغيير في شكل الصفحة يكون في `docs/site/build.mjs` وحده.
