# قائمة التحقق قبل الإصدار

**قابلة لإعادة التشغيل قبل كل إصدار.** ما تحكم عليه الأتمتة أعلاه،
وما لا تحكم عليه إطلاقًا أدناه — والثاني هو سبب وجود هذه الوثيقة.

---

## ١ · البوابات الآلية

```bash
npm run verify      # أنواع + clippy + fmt + ٢٠٢ اختبار وحدة + ٤٩ اختبار Rust
npm run test:e2e    # ١٢٣ اختبار Playwright + ٢٠ لقطة مرجعية
npm run app:build   # Luma.app
npm run selftest    # ٤٤ فحصًا داخل التطبيق + تسع ميزانيات مبوَّبة
```

الأربعة تخرج بحالة صفرية أو **لا إصدار**. `npm run selftest` يُشغِّل
النسخة المبنية، فيجب أن يسبقه `app:build`.

## ٢ · ما لا تحكم عليه الأتمتة إطلاقًا

كلها **داخل `Luma.app` مبنية**، بالماوس ولوحة المفاتيح معًا. لا متصفح
ولا خادم تطوير ولا لقطة.

### VoiceOver

- [ ] `⌘F5` ثم التنقّل إلى مساحة الكتابة: تُعلَن **منطقة تحرير نصية**
      لا عنصرًا مرسومًا.
- [ ] يقرأ نصًّا عربيًّا مشكولًا: «بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ».
- [ ] يقرأ نصًّا مختلطًا: «كتبت hello للعالم» بترتيبه المنطقي.
- [ ] يعلن اسم كل زر أيقونة بالعربية — لا اسمًا إنجليزيًّا ولا «زر».
- [ ] حالة الحفظ تُعلَن **بلا سحب التركيز من النص**.
- [ ] أثناء معاينة نسخة: تُعلَن المساحة **للقراءة فقط**.
- [ ] المكتبة والسجل يُعلَنان قائمةً بعدد عناصرها.
- [ ] شاشة الإعدادات تُعلَن **حوارًا باسمها**، وما خلفها لا يُقرأ.

### لوحة المفاتيح والتنقل

- [ ] **فعِّل «التنقل بلوحة المفاتيح»** (إعدادات النظام ← لوحة المفاتيح).
      وهو مطفأ افتراضيًا على macOS، وبدونه لا يصل `Tab` إلا الحقول
      النصية — في Luma وفي كل تطبيق أصلي.
- [ ] `Tab` يصل كل عنصر تفاعلي، والترتيب من اليمين إلى اليسار.
- [ ] حلقة التركيز ظاهرة على كل محطة، في **الثيمات الخمسة**.
- [ ] `Esc` يقشّر طبقة واحدة: ورقة الخط ← الإعدادات ← المحرر المريح ←
      اللوحة. ولا يخرج من وضعٍ لم يُقصد.
- [ ] `⌃⌘F` يدخل المحرر المريح ويخرج منه، والمؤشر لا يتحرّك.
- [ ] الأسهم تتنقّل بين تبويبات ورقة الخطوط وبين خياراتها.
- [ ] **الإعدادات مفتوحة: اكتب.** لا حرف يصل المستند خلفها.

### النظام والتبادل

- [ ] نسخ من Luma ولصق في TextEdit: النص نفسه بلا رموز اتجاه مدسوسة.
- [ ] لصق عربي من Safari ومن Notes: بلا تنسيق وبلا فساد اتجاه.
- [ ] قائمة السياق الأصلية تظهر بعناصرها (بحث، تدقيق، خدمات).
- [ ] الإملاء الأصلي في macOS يعمل داخل مساحة النص.
- [ ] إدراج من عارض المحارف ومن لوحة الرموز التعبيرية.
- [ ] `⌘Z` من القائمة ومن لوحة المفاتيح: مكدّس واحد، ودفقة لا حرفًا.

### العربية — [بطارية العربية](arabic-battery.md)

- [ ] النقر المزدوج يحدد كلمة عربية كاملة.
- [ ] التحديد بالسحب متصل بصريًا بلا فجوات.
- [ ] `Backspace` يحذف عنقودًا رسوميًا واحدًا مع تشكيله وهمزته.
- [ ] `Home` و`End` يصلان بداية السطر ونهايته **منطقيًّا**.
- [ ] الأسهم تتحرك كأعراف macOS.

### تقليل الحركة وتكبير النص — من النظام لا من Luma

- [ ] إعدادات النظام ← تفويض ← شاشة ← **تقليل الحركة**: كل انتقال فوري،
      ونبض مؤشر الحفظ متوقّف، **ولا وظيفة تُفقد**.
- [ ] إعدادات النظام ← تفويض ← شاشة ← **تكبير حجم النص**: لا أمر أساسي
      يُقصّ، ولا ينكسر المحرر.
- [ ] تكبير الشاشة (`⌥⌘8`): الواجهة صالحة.

### النافذة والمظهر

- [ ] تصغير وتكبير وملء الشاشة وتغيير الحجم: التخطيط صالح.
- [ ] **نظام بلغة عربية ونظام بلغة إنجليزية**: أزرار النافذة في جانبها
      الصحيح، وحالة الحفظ في الطرف المقابل ولا تقع تحتها.
- [ ] الثيمات الخمسة: الورقة متمايزة عن الخلفية في كلٍّ منها.
- [ ] تبديل الثيم والخط والحجم: المؤشر والتمرير محفوظان بلا وميض.

### حالات الخطأ — [سلوكها الموثَّق](error-behaviour.md)

```bash
LUMA_FAIL_WRITES=1 ./src-tauri/target/release/bundle/macos/Luma.app/Contents/MacOS/luma
```

- [ ] اكتب: تظهر «تعذّر الحفظ» بأيقونة ونصّ ولون.
- [ ] ادخل المحرر المريح: **الحالة تبقى ظاهرة** ولا يخفيها Zen.
- [ ] حاول فتح مستند آخر من المكتبة: **لا يُستبدل شيء**، ويظهر السبب.
- [ ] أغلق النافذة (`⌘W`): **لا تُغلق**، وتظهر فرصة الاسترجاع.
- [ ] أغلق مرة أخرى: الرسالة نفسها — لا إغلاق صامت على نصّ ضائع.
- [ ] أفسِد ملف مستند بنصّ ليس JSON: المكتبة تعرض البقية ولا تسقط،
      والملف يبقى على القرص كما هو.
- [ ] أفسِد ملف لقطة: السجل يعرض البقية، وقراءتها تُظهر خطأ محصورًا فيها.
- [ ] احذف ملف خط مستورد مختار ثم أعد الإقلاع: يعود إلى Almarai **قبل
      أول رسم للنص**.
- [ ] `kill -9` أثناء الكتابة ثم أعد الفتح: الملف سليم، والفقد لا يتجاوز
      خمس ثوانٍ.

## ٣ · ما لم يُقَس بعد — **بنود إطلاق لا اختيارية**

- [ ] **الميزانيات على أقدم جهاز مدعوم** (macOS 13.0). كل أرقام
      [ADR ٠٠١١](decisions/0011-performance-budgets.md) من Apple Silicon
      على macOS 26.6. `npm run selftest` هناك، ومقارنة النتيجة.
- [ ] **التشغيل الفعلي على macOS 13.0.** جرد
      [ADR ٠٠١٢](decisions/0012-minimum-macos.md) نظري من مصفوفات الدعم.
      خاصة: `inert` — وعليه تقوم سلامة النص خلف الشاشات. (قيس على
      macOS 26.6 فنجح، والفحص نفسه يُعيد القياس على ١٣٫٠ تلقائيًّا.)
- [ ] **تعارض نتيجة أداة مع سلوك التطبيق يُحسم لصالح التطبيق**، ويُسجَّل
      الفرق (`PLAN.md`).

## ٤ · التوقيع والتصديق — المرحلة ٨

### ما يمكن التحقق منه الآن، بلا شهادة توزيع

```bash
npm run release:adhoc
```

يبني ويوقّع بهوية عابرة **وبـHardened Runtime والاستحقاقات نفسها**، ثم
يشغّل التطبيق تحت تلك القيود. يكشف عطبًا مبكرًا: لو احتاج التطبيق
استحقاقًا لم يُمنح لسقط هنا قبل أن يسقط عند التصديق.

- [x] يعمل تحت Hardened Runtime **بلا استحقاق واحد** — قيس، والعلم
      `runtime` مثبَّت في التوقيع (`flags=0x10002`).
- [x] معرّف الحزمة في `Info.plist` هو `com.sultanart.luma`.
- [x] **مسار البيانات لم يتحرّك** بعد تغيير المعرّف: المستندات كما هي
      في `~/Library/Application Support/Luma/`، والاستئناف يعمل.
- [x] `OFL.txt` و`NOTICE.md` ملفان حقيقيان في
      `Contents/Resources/fonts/` لا مضمَّنان في الثنائي.

### ما يحتاج العضوية — **معلَّق**

- [ ] عضوية في برنامج مطوّري Apple (٩٩$ سنويًا).
- [ ] شهادة `Developer ID Application` — نزّلها وافتحها لتدخل السلسلة.
- [ ] بيانات التصديق:
      `xcrun notarytool store-credentials luma --apple-id … --team-id … --password …`
      (كلمة مرور **خاصة بالتطبيق** من `appleid.apple.com`، لا كلمة حسابك).
- [ ] `npm run release` — يوقّع ويصدّق ويثبّت التصديق ويبني DMG موقّعًا.
- [ ] `spctl --assess` يقبل التطبيق وDMG.

### التثبيت على حساب نظيف — **معيار اكتمال المرحلة**

- [ ] حساب macOS جديد على الجهاز، أو جهاز آخر لم تُبنَ عليه Luma.
- [ ] فتح DMG وسحب Luma إلى «التطبيقات».
- [ ] أول تشغيل **بلا أي تحذير من Gatekeeper** — لا «لا يمكن فتحه» ولا
      «مطوّر غير معروف».
- [ ] دورة كاملة: كتابة، حفظ، إغلاق، إعادة فتح، **استئناف النص نفسه**.
- [ ] `npm run selftest` على ذلك الجهاز، ومقارنة الميزانيات.
