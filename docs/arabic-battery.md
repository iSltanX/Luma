## كيف تُشغَّل

```bash
npm run app:build
LUMA_DEMO=1 ./src-tauri/target/release/bundle/macos/Luma.app/Contents/MacOS/luma
```

الفحص الذاتي داخل التطبيق:

```bash
LUMA_SELFTEST=1 ./src-tauri/target/release/bundle/macos/Luma.app/Contents/MacOS/luma &
sleep 3 && osascript -e 'tell application "Luma" to activate'
# النتيجة → ~/Library/Application Support/Luma/selftest-report.json
```

**النافذة يجب أن تكون في المقدمة:** macOS يعلّق `requestAnimationFrame`
للنوافذ المحجوبة. الفحص لا يتوقف إن حُجبت (فيه مهلة احتياطية)، لكن
أرقام الأداء لا تكون ذات معنى إلا والنافذة ظاهرة.

**لا بند يُعلَّم `✅` من متصفح أو خادم تطوير.** كل `✅` أعلاه مصدره الفحص
الذاتي داخل `Luma.app` أو اختبار وحدة على منطق خالص.

Playwright يشغّل البنود نفسها على طبقة الويب ككشف انحدار سريع على كل
تغيير — إشارة مبكرة لا شهادة اجتياز. حيث يظهر «Playwright» في الجدول
فالبند مُثبَت أيضًا داخل التطبيق.
