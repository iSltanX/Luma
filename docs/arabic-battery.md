# بطارية العربية

قائمة ثابتة تُشغَّل **داخل `Luma.app` مبنية** في نهاية المراحل ١ و٢ و٣ و٦ و٧. لا تُعاد صياغتها، ولا يُحذف منها بند بلا قرار مسجَّل في `docs/decisions/`.

`✅` مرّ · `⬜` لم يُختبر بعد في هذه المرحلة · `⚠️` قيد معروف بقرار

## كيف تُشغَّل

```bash
npm run app:build
LUMA_DEMO=1 ./src-tauri/target/release/bundle/macos/Luma.app/Contents/MacOS/luma
```

الأرقام من `LUMA_BENCH=1` → `~/Library/Application Support/Luma/probe-report.json`.

**لا بند يُعلَّم `✅` من متصفح أو خادم تطوير.** Playwright وLighthouse يساعدان على البنود ١–٦ و٢٥–٢٦ كإشارة مبكرة، ولا يُعتدّ بهما بديلًا.

## سجل المراحل

- **م١ — بوابة القدرات:** ١٣ بندًا مرّت. المتبقي يحتاج تفاعلًا يدويًا أو مراحل لاحقة. لا بند سقط.
